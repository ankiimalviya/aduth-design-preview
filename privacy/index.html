LOCAL DESIGN EXPLORATION

Website privacy

Updated 1 November 2026

Browsing this design preview

This separate website preview introduces Aduth and ULE. It includes a scripted walkthrough using fictional sample data. It has no signup form, analytics, account login, browser storage, or submission endpoint. Walkthrough choices stay in page memory and reset when you reload.

Fonts and technical requests

The website requests Satoshi font styles and files from CDNFonts. Your browser sends normal technical request information when loading them. Arial is used for headings and as a fallback.

External links and email

The waitlist buttons open the existing live ULE site, which has a separate privacy notice and early-access terms. Email actions are disabled in this review copy.

Questions

Use the contact link for questions about this website. Avoid including confidential information in general feedback.
